독자용 스토리 배포 안내 (v120)

[ZIP 구성]
index.html      독자가 실행할 시뮬레이터
images/         스토리에 사용되는 이미지 (경로 변경 금지)
사용안내.txt     이 파일

[PC에서 실행]
1. ZIP을 압축 해제합니다.
2. index.html과 images 폴더가 같은 위치에 있는지 확인합니다.
3. index.html을 더블클릭하여 브라우저에서 엽니다.
4. 사진과 배경이 정상적으로 보이는지 확인합니다.

[Cloudflare Pages 업로드]
1. ZIP의 압축을 해제합니다.
2. index.html과 images 폴더를 함께 Cloudflare Pages의 업로드 대상으로 선택합니다.
   (또는 이 두 항목이 있는 폴더 전체를 업로드합니다.)
3. 배포 후 사이트 주소로 접속해 이미지가 뜨는지 확인합니다.
4. 수정해서 재배포할 때는 새 index.html과 변경되거나 추가된 이미지 파일을 올립니다.
   기존 파일과 이름이 같은 이미지는 덮어씁니다. 사용하지 않는 이미지는 삭제할 수 있습니다.

[주의]
- index.html만 따로 보내면 이미지가 보이지 않습니다.
- 폴더 이름(images)과 상대 경로를 변경하지 마세요.
- 제작자 백업(JSON)은 기존 방식 그대로 사용합니다.
- 이 ZIP은 독자용입니다. 수정은 제작자 HTML에서 진행하세요.
- 외부 URL의 이미지는 ZIP에 저장하지 않으므로 해당 서버에 연결돼야 합니다.
- 프로필·배경처럼 고정된 위치의 파일명은 위치로 결정합니다. JPEG와 PNG는 같은 WebP 경로를 사용합니다.
- 갤러리처럼 고정 위치가 없는 사진은 원본 데이터 해시로 이름을 정합니다.
- GIF는 움직임 보존을 위해 원본으로 보관합니다.
